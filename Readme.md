# Meus estudos de QA (Quality Assurance)

Bem-vindo(a) ao meu repositório de estudos e práticas focado em **Garantia de Qualidade de Software (QA).**

O objetivo deste espaço é registrar minha evolução, conceitos aprendidos e os primeiros testes na área de QA.

## **Conceitos e ferramentas em aprendizado**

### Testes Manuais
Aqui pretendo documentar o que aprender sobre:
* Escrita de Casos de Teste (Test Cases)
* Reporte de Bugs (Bug Reports)

### Testes de API
Estudos focados em validar a comunicação entre sistemas (Backend), requisições e respostas.

### Testes Automatizados
* Futuras ferramentas de automação (Cypress ou Playwright)

## **Ferramentas utilizadas**
* **VS Code** (Editor de código)
* **Git & GitHub** (Controle de versão e portfólio)
* **Postman** (Plataforma para testes e desenvolvimento de APIs)
